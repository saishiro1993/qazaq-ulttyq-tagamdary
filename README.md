# Дәмді Дәстүр

Қазақ ұлттық тағамдары туралы дайын веб-қосымша.

## Мүмкіндіктер
- интерфейс толық қазақ тілінде;
- ұлттық тағамдар каталогы;
- атауы мен сипаттамасы бойынша іздеу;
- санаттар бойынша сүзгі;
- тағам туралы толық ақпарат;
- негізгі құрамы;
- қызықты деректер;
- таңдаулылар тізімі;
- браузерде таңдаулыларды сақтау;
- кездейсоқ тағам;
- шағын викторина;
- компьютер, планшет және телефонға бейімделген дизайн.

## Іске қосу
1. Архивті ашыңыз.
2. `index.html` файлын браузерде ашыңыз.
3. VS Code қолдансаңыз, Live Server арқылы да іске қосуға болады.

## Файлдар
- `index.html` — бет құрылымы
- `style.css` — дизайн және адаптив
- `script.js` — каталог, іздеу, таңдаулылар және викторина


## Нақты суреттер
Бұл нұсқада карточкалардағы суреттер Wikimedia Commons-тегі нақты фотолармен алмастырылды. Суреттер интернет арқылы жүктеледі, сондықтан оларды көру үшін браузерде интернет қосулы болуы керек.


## Сөз құрастыру тренажері
Қосымшаға ұлттық тағам атауларын әріптерден құрастыруға арналған жаттығу қосылды. Оқушы сурет пен қысқаша сипаттаманы көреді, аралас әріптерді таңдап сөз құрастырады, жауабын тексеріп, ұпай жинайды.
